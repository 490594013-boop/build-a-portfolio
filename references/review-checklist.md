## 常见"以为没问题其实有问题"的坑

| 现象 | 真相 |
|---|---|
| "右侧一条深色边" | 内容溢出了画框，导出把画布撑大 |
| "体积 34MB，应该能接受" | 多数投递平台限 10–20MB |
| "文字看不见是因为图糊" | 其实是文字被转成轮廓了，没有文字层 |
| "两页内容不重复啊" | 作者的记忆会自我保护；必须做机器去重 |
| "我改过术语了" | 可能只改了当前文件，历史文案 md 没改 |
| "格式统一了" | 首尾两页最容易例外（封面/结尾版式特殊） |

## F. 排版细节（设计作品集的门面，5 项）

| # | 检查 | 一键扫描方式 | 通过标准 |
|---|---|---|---|
| F1 | **ASCII 直引号混入** | 见下方脚本 | 0 处 |
| F2 | **中英文空格一致性** | 见下方脚本（按用户规则） | 0 处违规 |
| F3 | **日期漏「月」** | `grep -oE "\d{4}年\d+(中旬\|下旬\|上旬)"` | 0 处 |
| F4 | **半角括号** | `grep -o "[(]"` 在中文语境 | 0 处（或确认是有意的）|
| F5 | **数字与单位** | 同 F2 | 按规则统一 |

```python
# F1 + F2 扫描器：把日期/百分比/英文缩写遮住，只查剩下的 数字↔中文 边界
import xml.etree.ElementTree as ET, re, os
NS = "{http://www.w3.org/2000/svg}"; CJK = r'\u4e00-\u9fff'

def mask(s):                       # 按约定不需要空格的，先遮掉
    s = re.sub(rf'\d+\s*[年月日]', '□', s)      # 日期
    s = re.sub(r'\d+(\.\d+)?\s*%', '□', s)      # 百分比
    s = re.sub(r'[A-Za-z]+\d*\.?\d*', '□', s)   # 纯英文 / 版本号
    return s

for i in range(18):
    f = f"第{i}页.svg"
    if not os.path.exists(f): continue
    for t in ET.parse(f).getroot().iter(NS + "text"):
        s = "".join(t.itertext()).strip()
        if not s: continue
        if '"' in s: print(f"[F1] 第{i}页 直引号：{s[:50]}")
        for m in re.finditer(rf'(\d)([{CJK}])|([{CJK}])(\d)', mask(s)):
            print(f"[F2] 第{i}页 待加空格：…{s[max(0,m.start()-8):m.end()+8]}…")
```

## G. 数据验算与结构核对（3 项）

| # | 检查 | 做法 |
|---|---|---|
| G1 | **每个百分比反推** | 用首尾数字验算；`48%→51%` 是 **+3pp** 不是 +3% |
| G2 | **成果页标签与数字配对** | 纯文本提取会把左右列串行 → **按 x,y 坐标复原**再判断 |
| G3 | **归一化与基线** | 大促月 / 业务交接 / 多因素 → 必须写"不简单归因"；基线用项目自己的起点 |

```python
# G2 坐标复原（判断每个数字属于哪个标签）
import xml.etree.ElementTree as ET
NS = "{http://www.w3.org/2000/svg}"
root = ET.parse("第16页.svg").getroot()
rows = []
for t in root.iter(NS + "text"):
    for sp in t.iter(NS + "tspan"):
        s = "".join(sp.itertext()).strip()
        if s:
            rows.append((float(sp.get("y", 0)), float(sp.get("x", 0)), s))
for y, x, s in sorted(rows):
    print(f"y={y:>5} x={x:>5}  {s}")
# 同一列（x 接近）= 同一指标；上下 = 首尾值
```
