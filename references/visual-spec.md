# 视觉规范

## 1. 画布

| 项 | 规格 |
|---|---|
| 主页 | **1920 × 1080**（16:9） |
| 长页 | 宽固定 1920，高按内容（本项目出现 1252 / 1819 / 2244 / 3052 / 3917） |
| 出血 | **不要出血**。画框开 `Clip content`，否则导出会撑大画布 |

> 混用 16:9 与长页是可接受的（长页承载截图多的方案页），但要在规范里写明，
> 并接受"全屏放映时高度不一致"这个代价。

## 2. 配色（暖浅色主调，本项目定稿）

| 用途 | 色值 |
|---|---|
| 页面底色 | `#F7F6F4`（暖浅灰） |
| 面板 / 卡片 | `#F4F0EA`（暖米色） |
| 强调色 | `#FB7701`（橙，品牌色） |
| 警示 / 痛点标记 | `#E02E24`（红，克制使用） |
| 主文字 | `#2B2B2B` |
| 次文字 | `#6B6560` |
| 弱文字 | `#8A8580` |
| 极弱 / 页脚 | `#B5AFA7` |
| 分隔线 | `#E5DFD7` |
| 橙的浅色底（高亮块） | `#FBE6D0` |
| 橙色深字（确保对比度） | `#C25A00` |

**原则**：整页靠**明度与留白**分层，橙色是唯一主强调色；红色只用来标"问题 / 旧状态"。

## 3. 页眉系统（每页统一）

```
┌──────────────────────────────────────────────────────────┐
│ 章节名（25px 粗）                          编号（25px 粗）│  ← y≈70
│ 英文副标题（16px 弱灰）              项目名（16px 弱灰）  │  ← y≈100
└──────────────────────────────────────────────────────────┘
```

- 左：中文章节名 + 英文副标题（英文用小一号的弱灰，带字距）
- 右：编号 + 项目名
- **右上的编号是项目编号还是页码必须问清楚**。如果全篇都是 `01` 而它其实是项目编号，那这份 PDF 就**没有页码**，建议补书签

## 4. 小标题：代码注释风格

本项目采用的一个低成本高识别度手法：

```
/*现状
/*初稿方案
/*最终方案
/*现在的人 ——  盘点组员 / 盘点组长
```

统一用 `/*` 开头，让章节名有"代码注释"的技术感，与 B 端项目气质契合。**全篇统一**，不要有的用有的不用。

## 5. 组件规格

| 组件 | 规格 |
|---|---|
| 面板 | `#F4F0EA`，圆角 20，无描边 |
| 左侧强调条 | `#FB7701`，宽 4，高度同面板 |
| 阶段 pill | 描边圆角胶囊，文字居中 |
| 序号徽标 | 圆形填充 `#FB7701`，白字 13–14px |
| 大号水印数字 | 96px、`#EAE3D8`（比面板略深一档） |
| 高亮文本块 | `#FBE6D0` 圆角底 + `#C25A00` 文字 |
| 分隔线 | 1px `#E5DFD7` |
| 箭头 | 实心三角 `<polygon>` |

## 6. 字体

| 用途 | 字体栈 |
|---|---|
| 中文 | `"PingFang SC","Hiragino Sans GB","Microsoft YaHei",sans-serif` |
| 英文 / 数字 | `"Helvetica Neue",Arial,sans-serif` |
| 代码纹理 | `"SF Mono",Menlo,Consolas,monospace` |

## 7. 信息图的三条经验

1. **信息图宁少勿多**：一页只表达一个结构（流程 / 对比 / 分层 / 环）。塞两种结构会失焦。
2. **能用"前后对照"就不要用"并列罗列"**：`旧状态 →（箭头）→ 新方案` 比四个并列卡片更有说服力。
3. **数字要成为视觉高潮**：`30~40 分钟 → 约 15 分钟` 用大字号放页面下方作为收尾重音。

## 8. 手写 SVG 的坑

| 坑 | 说明 | 解法 |
|---|---|---|
| `<marker>` 箭头不显示 | 部分渲染器（如 macOS `sips`）不支持 `marker-end` | 算切向写 `<polygon>` |
| 字体缺失导致回流 | 文本宽度按字体变化 | 关键文本给出显式 `x`，或转曲后交付 |
| 中英文混排间距 | 需要手动留空格 | 在中文与英文/数字之间加空格 |
| 文本溢出 | SVG 不自动换行 | **手动断行**，每行字符数按宽度算好 |

## 9. 导出避坑（Figma）

| 场景 | 正确做法 |
|---|---|
| 要**别人能读文字**（审查 / 可搜索） | 导 **SVG**，且**不要勾 Outline text / 转为轮廓** |
| 面试用 PDF | Figma 原生 PDF 导出会把文字转轮廓，**这是正常的**，面试人工翻看够用 |
| 导出后画布比画框大 | 画框开 `Clip content` |
| 多页合并后尺寸不一 | 每个画框尺寸本来就不同；合并后用 `scripts/audit_pdf.py` 核对 |

> **不要用 `sips` 做 SVG → PDF 的转换**：它会把整页栅格化成一张位图（矢量全丢、文字全无），
> 比你现有的 PDF 更差。
